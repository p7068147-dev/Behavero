### Behavero

**Local-first software behavior investigation tool**

Behavero helps users investigate changes to a directory by capturing filesystem snapshots and comparing them to identify created, deleted, and modified files. It can also run a specified command and report the filesystem changes observed around that execution.

- Written in Python
- Designed for local use
- Includes automated tests
- No third-party runtime dependencies

**Status:** Early development — v0.1.0
